# Свадебное приглашение

Готовый статический сайт без сборки, React и сторонних JS-библиотек.

## Изменение данных

Откройте `script.js`. В самом начале находится `weddingData`: имена, дата, город, ресторан, адрес и ссылка 2ГИС. Инициалы, заголовок вкладки и обратный отсчёт обновляются автоматически. Программа вынесена ниже в `weddingProgram`.

Замените `ССЫЛКА_2GIS` на прямую HTTPS-ссылку заведения из 2ГИС. Пока она не заполнена, кнопка открывает поиск указанного адреса в 2ГИС. Адрес из макета не проверялся как фактический адрес ресторана.

Таймер считает до 00:00 даты свадьбы по времени Бишкека (UTC+6). В день свадьбы показывает нули и поздравительную подпись.

## Просмотр

Можно открыть `index.html` напрямую. Для локального сервера:

```sh
python3 -m http.server 8080
```

Откройте http://localhost:8080. При каждой новой загрузке страницы показывается конверт. Предусмотрен системный режим уменьшенной анимации.

## Файлы

- `index.html` — семь частей приглашения, включая конверт.
- `style.css` — мобильная композиция, адаптация и анимации.
- `script.js` — данные, программа, таймер и открытие.
- `assets/images/` — оптимизированные WebP-фоны и SVG-декор.
- `assets/fonts/` — локальный шрифт Cormorant Garamond и его лицензия.

Фоны созданы встроенным imagegen по приложенным референсам, без людей и надписей. Запросы: закат над горным озером в цветочной арке с кремовой тканью и свечами; кремово-мраморная поверхность с золотыми прожилками, цветами по краям и тканью снизу.

## Проверка

Проверено в Chrome: 390×844, 320×568, 844×390 и 1440×1000. Проверены отсутствие горизонтального скролла, размеры текста, загрузка изображений, слои конверта, направление выхода письма, пять пунктов программы и системный режим уменьшенной анимации. Ошибок JavaScript и загрузки файлов не обнаружено.

Изображения в `assets/images`: `sunset-arch.webp`, `cream-marble-flowers.webp`, `blush-flowers.webp`. Последний запрос imagegen: отдельная прозрачная композиция из нежно-розовых роз, небольших кремовых цветов и оливковых листьев в тёплом закатном свете.

## Обновление дизайна и конверта

Внутренние секции используют чистый тёплый кремовый фон с лёгкой фактурой и одним небольшим цветочным акцентом. Главный экран и финал сохраняют закатную композицию. Лепестков три, между их появлениями есть длительные паузы.

Слои конверта: `envelope-back` → `envelope-flap` после полного открытия → `envelope-interior` с `letter` → `envelope-front` → закрытый `envelope-flap` → `wax-seal`. Сложенное письмо физически лежит под передней стенкой, без скрытия через opacity. Передняя стенка и дно кармана закрывают нижнюю часть письма при подъёме. После подъёма предусмотрено 2,2 секунды для чтения.

Дополнительно проверено на 390×844, 375×812 и 360×780, включая изменение ширины и высоты окна во время подъёма письма. Начальный кадр сравнивается с кадром, в котором письмо полностью убрано из отрисовки: отличий нет.

## Цельная editorial-композиция

Кремовые секции объединены общим фоном с деликатной мраморной фактурой, мягкими световыми градиентами и переходами ткани. На телефоне программа оформлена вертикальной timeline без карточек; на desktop — горизонтальной. Стрелки, геолокация и события используют SVG line-icons с единым stroke и фиксированными контейнерами. Цветочные акценты имеют параллакс до 7px; основное появление элементов занимает 1–1,2 секунды. Режим уменьшенной анимации сохраняется.

Проверено целиком на 360, 375, 390, 430 и 1440px: заголовки и иконки помещаются, все изображения загружаются, горизонтального скролла и ошибок JavaScript нет. Механика конверта дополнительно проверена при смене ширины 360 → 375 → 430 → 390px во время подъёма письма.
